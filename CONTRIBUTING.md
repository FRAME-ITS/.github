# Contributing to FRAME

Thank you for helping to improve FRAME.

1. **Report a problem or propose a change** as an issue in the repository it concerns: [FRAME](https://github.com/FRAME-ITS/FRAME/issues) for the model and the tool, [FRAME-online](https://github.com/FRAME-ITS/FRAME-online/issues) for the website, [.github](https://github.com/FRAME-ITS/.github/issues) for topics of the whole organisation. Name the element, diagram or page and the release you use.
2. **Prepare a change** as a pull request. Keep one topic per pull request and describe what changes and why.
3. **Review and decision:** the FRAME Maintainers classify each change by its impact. Corrections are reviewed by two Maintainers; changes of content and methodology follow the Technical Change Decision Process. See [Contribute](https://frame-its.github.io/FRAME-online/contribute/) on the website.

Repositories with their own CONTRIBUTING.md (FRAME, FRAME-online) describe their specific workflow there. Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).
