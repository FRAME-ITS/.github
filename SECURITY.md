# Security

FRAME repositories contain an architecture model, documentation and a website; they do not run services that process personal data.

If you find a security problem – for example exposed credentials, a compromised download or a vulnerability in a workflow or script – **do not open a public issue**. Write to contact@frame-online.eu, or use GitHub's private vulnerability reporting where it is enabled. The FRAME Maintainers will confirm the report and inform you about the fix.
